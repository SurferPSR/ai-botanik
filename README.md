# Botanik

Мобильное приложение на Flutter для определения растений по фотографии и рекомендаций по уходу.

## Запуск

1. Установите Flutter SDK и Android Studio / Xcode.
2. Выполните `flutter pub get`.
3. Запустите `flutter run`.

Текущая версия содержит интерфейс MVP, выбор фото из галереи или камеры и демонстрационный режим анализа. Следующий шаг — подключение backend и API распознавания растений.
